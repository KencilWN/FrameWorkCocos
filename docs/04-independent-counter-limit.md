# 独立小练习：给余额增加上限

前置：计数器初始100、每次加5；用户已解释回调引用、数据与显示、实例状态、生命周期和节点引用。该练习用于观察能否独立把需求写成条件与状态变化，不预先给完整实现。

## 需求

只修改 CoinCounter 的 addCoin 方法，其他按钮、字段初始值、显示与生命周期逻辑保持当前需求。

- 余额上限150。
- 每次仍尝试增加5。
- 本次增加会超过150时，保留原余额，在控制台提示「已达上限」，结束这次操作。
- 成功增加后，保留原有事件通知，使文字同步。
- 拒绝增加时没有发生数据变化，无需发送余额变化事件。
