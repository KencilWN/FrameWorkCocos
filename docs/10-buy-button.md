## 1. 组件增加引用与配置

在CoinCounter增加：

```ts
@property(Button)
buyButton: Button | null = null;

@property
purchasePrice: number = 30;
```

buyButton是引擎组件引用，purchasePrice是本例购买价格。Wallet继续只接收金额，不依赖按钮或商品配置。

在onLoad和onEnable现有引用检查中补入!this.buyButton，onLoad错误信息同步包含新引用。原有初始化与其他按钮逻辑保留。

## 2. 自己实现buy回调

新增private buy(): void，参照addCoin的调用方式自行完成：

1. 钱包未就绪时结束。
2. 调用一次this.wallet.trySpend(this.purchasePrice)，保存返回结果。
3. 失败时在组件打印“扣款失败”并结束；不修改余额或发送金币变化通知。
4. 成功后发出COINS_CHANGED事件，参数为钱包当前余额；可打印“扣款成功”。

余额不足和非法费用都由trySpend拒绝，本轮boolean不区分拒绝原因。组件直接使用结果，不再复制余额判断和扣款公式。

onEnable中增加：

```ts
this.buyButton.node.on(Button.EventType.CLICK, this.buy, this);
```

onDisable中成对增加：

```ts
this.buyButton?.node.off(Button.EventType.CLICK, this.buy, this);
```

方法名、回调引用和target对应。onEnable原有刷新逻辑保持，恢复界面时读取同一个钱包。
